# ⏱️ Stopwatch

A simple and easy-to-use stopwatch application built using HTML, CSS, and JavaScript.

## Features

* Start the stopwatch
* Pause the stopwatch
* Reset the stopwatch

## How to Use

1. Click **Start** to begin the stopwatch.
2. Click **Pause** to stop the timer.
3. Click **Reset** to return the stopwatch to `00:00:00`.

## Technologies Used

* HTML
* CSS
* JavaScript
